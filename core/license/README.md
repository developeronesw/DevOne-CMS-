# DevOne 2.0 Licensing

DevOne CMS 2.0 is proprietary software and uses a single commercial Network entitlement model.

## Product rules

- A fresh installation is usable as a single-site CMS without a paid license.
- A commercial Network License unlocks Network/Multi-Site functionality.
- One successfully activated Network License Key is permanently bound to one DevOne CMS Installation.
- The same activation key cannot authorize another independent Installation.
- A Network entitlement authorizes unlimited Sites within its bound Installation.
- Annual Network entitlements expire according to their purchased term.
- A 99-Year Network entitlement begins on successful activation and expires 99 years later.
- Expired, invalid, revoked, or unverifiable entitlements fail closed to single-site capability.
- License enforcement is Core-owned; extensions cannot bypass it.

The provider is intentionally abstract. DevOne CMS 2.0 does not ship the production License Server. The separate Cloudflare License Server will be implemented after the 2.0.0 CMS release is complete.
