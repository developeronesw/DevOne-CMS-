# DevOne CMS Core 1.7.4 Stable

Official market release of the GPL-licensed DevOne CMS Core by Developer One Inc.

## Install
1. Upload/extract the package to the web root.
2. Browse to the site URL and complete the seven-step installer.
3. Remove or protect installer access after installation as directed by the installer.

## Distribution profile
- No bundled third-party/marketplace plugins.
- No installed `config.php`, credentials, logs, backups, cache, user uploads, or update staging data.
- Includes the two built-in DevOne Core themes and the official Developer One brand assets.
- Core remains GPL v3 or later; optional marketplace, licensing and hosted services are separate services.

See `RELEASE-NOTES-1.7.4-STABLE.md` for the release delta.
