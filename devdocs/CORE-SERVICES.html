Core Services

One consistent, discoverable API for plugins, themes, modules, libraries, and marketplace products—with a backward-compatibility bridge that keeps established DevOne helpers working.

Backward compatibility

Existing plugins, themes, modules and libraries do not need immediate rewrites. Established procedural helpers remain supported while new development adopts the service API.

Established code

$value = get_setting('my_key'); $media = devone_media_query('images'); devone_mail($to, $subject, $html); add_action('devone_head', $callback);

Recommended code

$value = DevOne::settings()->get('my_key'); $media = DevOne::assets()->query('images'); DevOne::mail()->send($to, $subject, $html); DevOne::events()->on('devone_head', $callback);

Marketplace standard

Certified packages should use the shared services instead of creating duplicate systems.
