Official Core Service

DevOne Assets API

One shared media layer for every plugin, theme, module, builder, and official DevOne product. Upload once, select anywhere, track usage, and keep the ecosystem fast.

One library. Zero duplicate systems.

Public-facing media must go through DevOne Assets. Installation packages, backups, source files, temporary imports, and private configuration belong in protected operational storage.

PHP service

$assets = DevOne::assets();

$result = $assets->upload($_FILES['image'], [
    'folder'  => 'auto',
    'purpose' => 'one-slider',
]);

$asset = $assets->find((int) $result['asset']['id']);
$url   = $assets->url($asset['id']);

Primary methods

MethodPurpose
upload()Validate, sort, store, and register public media.
search()Query permission-aware media records.
find()Read one public asset record.
update()Update supported metadata.
replace()Replace the underlying file while preserving asset identity.
attach() / detach()Track where an asset is used.
duplicates()Find matching files by content.

Shared Asset Picker

DevOneAssets.open({
    types: ['images', 'videos'],
    multiple: false,
    purpose: 'one-slider',
    onSelect(asset) {
        console.log(asset.id, asset.url);
    }
});

The compatibility alias DevOneMedia.open() remains available.

Usage tracking

DevOne::assets()->attach(
    $assetId,
    'plugin',
    'one-slider:12',
    'Homepage hero background'
);

Extensions should detach old references when content changes and warn before deleting assets that are still in use.

Security requirements

Verify permissions and CSRF tokens, use the Core uploader, rely on detected MIME types, escape output, store IDs rather than paths, and respect user, site, and multisite boundaries.

Marketplace certification

Certified extensions must not create a second public media library, duplicate selected files, or call raw upload functions for content media. The shared picker and Assets service are the default standard.

Backward-compatible migration

Add asset-ID fields while continuing to read old URLs during a transition period. Never delete legacy values until the extension has safely migrated saved records.

$url = $assetId
    ? DevOne::assets()->url($assetId, $legacyUrl)
    : $legacyUrl;
