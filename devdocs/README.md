# DevOne CMS Developer Documentation

Start with **GETTING-STARTED.md**, then choose the extension type you are building.

- `CORE-SERVICES.md` — official stable developer API.
- `HOOKS-AND-EVENTS.md` — actions, filters, and custom events.
- `THEMES.md` — presentation packages and templates.
- `PLUGINS.md` — focused CMS extensions.
- `MODULES.md` — complete application features.
- `LIBRARIES.md` — ordered CSS and JavaScript packages.
- `API-BUILDER.md` — authenticated CRUD APIs.
- `PACKAGE-SIGNING.md` — hashes and official package signatures.
- `SECURITY.md` — permissions, CSRF, escaping, uploads, and secrets.

- `RUNTIME-LOADER.md` — lazy runtime contexts, lifecycle migrations, and performance rules.
